# MOHSIN EMPIRE LIVE — Streamlit AI Toolkit

A neon-styled Streamlit web app packing several Gemini-powered tools: an SEO content generator, a Drive bot processor, and a 3D studio helper. One app, multiple AI utilities.

## What's inside (`app.py`)

- `hacker_seo` — generates SEO content with Gemini AI.
- `drive_bot_processor` — processes bot tasks against Google Drive.
- `get_3d_studio` — AI-assisted 3D studio workflow.
- `main` — the Streamlit app entry point (neon UI).

## Run it locally

```bash
pip install -r requirements.txt
streamlit run app.py
```

## Tech stack

Python · Streamlit · Gemini AI

> **Security note:** a Gemini API key was committed directly in `app.py`. Revoke it in Google AI Studio and move the key to an environment variable or Streamlit secrets before sharing or deploying.
